## 1. Цель задачи

1. **Реализовать интерактивную панель «📊 Количество проблемных логов за выбранное время и Корреляция сервисов» (`src/components/ProblemLogsAndCorrelationPanel.tsx`):**
   - Отвечает на главный вопрос пользователя: *«Сколько проблемных логов произошло за определённое время в каждом сервисе и как ошибки в разных сервисах связаны между собой?»*
   - **Интерактивный выбор отрезка времени:**
     - Быстрые цветные кнопки-пресеты:
       - `🔥 Только время аварии (пик сбоя)`
       - `📅 Весь доступный период логов`
       - `⚡ Первые минуты начала сбоя`
       - `🎛️ Свой интервал времени` (два удобных выпадающих списка / ползунка `Начало интервала` и `Конец интервала` по временным корзинам `timeline`).
   - **4 крупные разноцветные сводные карточки за выбранный отрезок времени:**
     1. **Рубиновая карточка (`--color-ruby`):** `Всего проблемных логов (Ошибок)` за выбранное время (крупное число + сколько это в среднем в минуту).
     2. **Янтарная карточка (`--color-amber`):** `Ошибок в первопричине` (имя главного сервиса + сколько ошибок дал именно он).
     3. **Фиолетовая карточка (`--color-violet`):** `Каскадных ошибок в зависимых сервисах` (сколько ошибок вызвано цепной реакцией).
     4. **Изумрудная карточка (`--color-emerald`):** `Отсеяно фонового шума` (сколько логов не относятся к аварии).
   - **Многоцветный интерактивный график количества проблемных логов по времени (SVG):**
     - Столбчатый или слоистый график по временным интервалам (`bucket` из `analysis.timeline`, а при пустом `timeline` — автоматическая реконструкция распределения по `onset_time` и `incident_rate_per_min` / `baseline_rate_per_min` гипотез, чтобы график ВСЕГДА был наполненным и наглядным!).
     - Каждый сервис окрашен в свой уникальный яркий цвет из `getServiceColor(service)`.
     - При клике по столбцу времени или наведении показывается точная разбивка: сколько проблемных логов дал каждый сервис в эту минуту.
   - **Понятная таблица и визуальная карта «Корреляция ошибок и количество логов за выбранное время (По каждому шаблону логов + Сводно по сервисам)»:**
     - В панели должен быть удобный переключатель режима отображения в 1 клик:
       - **`📋 По каждому шаблону логов (Детально по типам ошибок)`** *(включён по умолчанию)* — показывает статистику и корреляции **для каждого отдельного шаблона лога (`Hypothesis` / `template_id`)** в выбранном периоде времени!
       - **`📦 Сводно по сервисам (Все проблемные логи за период)`** — группирует и суммирует все проблемные логи по микросервисам за выбранный отрезок времени.
     - **Что отображается для каждого шаблона логов в выбранном отрезке времени:**
       - **Колонка 1: Шаблон лога, Сервис и его роль в аварии** (цветной бейдж сервиса + русский бейдж роли: `🔴 Первопричина`, `🟠 Следствие`, `🟡 Симптом`, `🟢 Фоновый шум` + файл/строка `source_place` + читаемый текст самого шаблона ошибки `template_text`).
       - **Колонка 2: Количество логов этого шаблона за выбранный отрезок времени** (точное расчётное количество срабатываний именно этого шаблона в выбранном интервале времени `С ... По ...` с учётом `onset_time`, `baseline_rate_per_min` и `incident_rate_per_min` + цветная полоска доли от всех проблемных логов).
       - **Колонка 3: Изменение частоты шаблона («Было до аварии → Стало»)** (например: `0 / мин → 60 / мин`, бейдж `Рост в 60 раз`).
       - **Колонка 4: Сдвиг по времени от первопричины** (`Начался первым (0 сек)`, `Через +2 сек`, `Через +4 сек`, `Шёл постоянно`).
       - **Колонка 5: Корреляция шаблона с другими шаблонами (`lead_lag_peers` + связь с первопричиной в %):**
         - Наглядная цветная шкала `0% .. 100%` (фиолетовый/рубиновый для высокой связи `>75%`, янтарный для средней `40..75%`, изумрудно-серый для шума `<30%`).
         - Показывает все связанные шаблоны из других сервисов (`peer_service`, `peer_template`, `lag_seconds`, `correlation_r * 100%`) и человеческое пояснение на русском:
           - *«Сильная связь (96%) с шаблоном в billing-db-proxy (pool_manager.go:84): эта ошибка повторяет волну первопричины с задержкой +2 сек»*;
           - *«Связи с аварией нет (0%): частота этого шаблона не менялась»*.
         - При клике на строку шаблона раскрывается наглядная карточка сравнения **«Связь шаблона А ↔ шаблона Б»** (тексты обоих шаблонов бок о бок, разница во времени старта и процент корреляции).
